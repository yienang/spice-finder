# Spice Finder
Find spicy restaurants around Brisbane via a heatmap and rate how spicy they are.
Link: https://spice-finder.onrender.com

Initially gathers data from reviews using Google Places API and has Claude Haiku give a spice level. New ratings gradually override this for more accuracy.

## How to use it
- Zoom into the map to see restaurant pins, or zoom out for the heat-map (darker = spicier)
- Click a pin to rate how spicy a restaurant is
- Check the leaderboard and recent ratings tabs to see other people's ratings.
